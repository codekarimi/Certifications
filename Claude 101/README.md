## 📚 What I Learned

The course takes a beginner from a first conversation to working with Claude across tools, files, and the web. The lesson titles below come from the official course outline.

### Module 1 — Meet Claude

I learned what Claude is, how to hold an effective first conversation, and how to improve results by refining prompts. I also learned how the desktop app supports three different ways of working.

**Key Concepts**
- What Claude is and what it is well suited for
- Structuring a first conversation: context, task, and desired output
- Writing clear prompts and iterating when results miss the mark
- The AI Fluency framework (delegation, description, discernment, diligence) for getting better outcomes
- The three "shapes of work" in the desktop app: working turn by turn (Chat), handing work off (Cowork), and building software (Code)
- Recognizing which shape a task calls for

**Hands-on Skills Gained**
- I can write a clear prompt with context, constraints, and a target format
- I can refine a weak answer by giving specific feedback instead of starting over
- I can choose the right mode for a task

**Tools/Technologies:** Claude (web and desktop app), Chat, Cowork, Code

---

### Module 2 — Organizing Your Work and Knowledge

This module covered giving Claude reusable context and turning conversations into finished work products.

**Key Concepts**
- **Projects:** persistent instructions and reference files shared across conversations
- **Artifacts:** creating and sharing documents, decks, and designs
- **Skills:** packaged, reusable instructions Claude applies to matching tasks
- Why reusable context saves time and improves consistency

**Hands-on Skills Gained**
- I can set up a Project with instructions and source documents for a recurring task
- I can generate an Artifact, refine it through conversation, and share it
- I can explain when a Skill is a better fit than re-typing the same prompt

**Tools/Technologies:** Projects, Artifacts, Skills

---

### Module 3 — Expanding Claude's Reach

This module covered connecting Claude to the tools and information where work already happens.

**Key Concepts**
- **Connectors** for linking Claude to external tools and data
- **Enterprise Search** for querying company knowledge (Team/Enterprise plans)
- **Research** mode for multi-step deep dives across the web
- Verifying sources and checking claims before relying on results

**Hands-on Skills Gained**
- I can decide when a connector, search, or research run is the right tool
- I can frame a research question so the output is usable
- I can review cited sources critically rather than accepting answers at face value

**Tools/Technologies:** Connectors, Enterprise Search, Research

---

### Module 4 — Putting It All Together

The closing lessons showed role-based use cases and other places Claude is available.

**Key Concepts**
- Use cases by role (for example marketing, writing, analysis, operations)
- Claude Code, Claude Tag, Claude Design, Claude for Microsoft 365, and Claude in Chrome
- Choosing the entry point that fits the work

**Hands-on Skills Gained**
- I can map my own recurring tasks to specific Claude features
- I can identify which Claude product fits a given workflow
- I completed the course quiz to earn the certificate

**Tools/Technologies:** Claude Code, Claude Tag, Claude Design, Claude for Microsoft 365, Claude in Chrome
